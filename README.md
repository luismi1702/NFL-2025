# 🏈 NFL 2025 — Statistical Analysis Suite

A collection of Python scripts for in-depth NFL statistical analysis using **nfl_data_py** and advanced metrics. Built for content creation, pre-game previews and weekly performance reporting.

## 📊 What this project does

This project automates the extraction, processing and visualization of NFL play-by-play and player data to generate analytical content — including weekly graphics, team reports, QB comparisons and matchup breakdowns.

## 🗂️ Scripts overview

| Script | Description |
|--------|-------------|
| `DatoSemana.py` | Weekly stat of the week graphic |
| `MVPsSemana.py` | Weekly MVP selection by position |
| `MVPsSeason.py` | Season-long MVP rankings |
| `Previas.py` | Pre-game matchup previews |
| `matchup.py` | Head-to-head team matchup analysis |
| `resumen_partido.py` | Post-game summary report |
| `informe_equipo.py` | Full team report card |
| `comparador_qbs.py` | QB comparison tool |
| `QBsTotalEPA.py` | QB ranking by total EPA |
| `RankingEPAadjustado.py` | Adjusted EPA ranking |
| `qb_presion.py` | QB performance under pressure |
| `oline_presion.py` | O-Line pressure rate analysis |
| `coberturas.py` | Coverage scheme breakdown |
| `ataque_vs_personal_ofensivo.py` | Offense by personnel grouping |
| `ataque_vs_personal_defensivo.py` | Offense vs defensive personnel |
| `defensa_vs_personal_ofensivo.py` | Defense vs offensive personnel |
| `play_action.py` | Play-action efficiency stats |
| `mapa_pases_por_zona.py` | Pass location heatmap |
| `target_share.py` | Target share by receiver |
| `cuarto_down.py` | 4th down decision analysis |
| `valor_turnovers.py` | Turnover value (EPA-based) |
| `power_rankings.py` | Weekly power rankings |
| `season_arc.py` | Team performance arc over the season |
| `draft_grid.py` | Draft pick visualization |
| `draft_success.py` | Draft class performance evaluation |
| `proe.py` | Points above replacement (PROE) |

## 🛠️ Tech stack

- **Python 3.10+**
- `nfl_data_py` — NFL play-by-play and player data
- `pandas` — Data manipulation
- `matplotlib` / `PIL` — Visualization and graphic generation
- `numpy` — Statistical calculations

## 🚀 Getting started

```bash
git clone https://github.com/luismi1702/NFL-2025.git
cd NFL-2025
pip install nfl_data_py pandas matplotlib numpy pillow
python power_rankings.py
```

## 📌 Use case

Originally developed to power **Mineros Spain** — NFL analytics content in Spanish. Scripts generate ready-to-publish graphics for social media and weekly editorial content.

# 🏈 NFL 2025 — Suite de Análisis Estadístico

Colección de scripts en Python para el análisis estadístico avanzado de la NFL usando **nfl_data_py** y métricas avanzadas. Desarrollado para la creación de contenido, previas de partidos e informes de rendimiento semanales.

## 📊 Qué hace este proyecto

Este proyecto automatiza la extracción, procesamiento y visualización de datos play-by-play y de jugadores de la NFL para generar contenido analítico — incluyendo gráficos semanales, informes de equipo, comparativas de QBs y análisis de matchups.

## 🗂️ Descripción de los scripts

| Script | Descripción |
|--------|-------------|
| `DatoSemana.py` | Gráfico del dato estadístico de la semana |
| `MVPsSemana.py` | Selección de MVPs semanales por posición |
| `MVPsSeason.py` | Rankings de MVPs a lo largo de la temporada |
| `Previas.py` | Previas de los partidos de la semana |
| `matchup.py` | Análisis de enfrentamiento entre equipos |
| `resumen_partido.py` | Resumen estadístico post-partido |
| `informe_equipo.py` | Informe completo de un equipo |
| `comparador_qbs.py` | Comparativa entre QBs |
| `QBsTotalEPA.py` | Ranking de QBs por EPA total |
| `RankingEPAadjustado.py` | Ranking por EPA ajustado |
| `qb_presion.py` | Rendimiento del QB bajo presión |
| `oline_presion.py` | Análisis de presión de la línea ofensiva |
| `coberturas.py` | Desglose de esquemas de cobertura |
| `ataque_vs_personal_ofensivo.py` | Ataque según agrupación de personal ofensivo |
| `ataque_vs_personal_defensivo.py` | Ataque frente a personal defensivo |
| `defensa_vs_personal_ofensivo.py` | Defensa frente a personal ofensivo |
| `play_action.py` | Eficiencia en jugadas de play-action |
| `mapa_pases_por_zona.py` | Mapa de calor de pases por zona del campo |
| `target_share.py` | Distribución de targets por receptor |
| `cuarto_down.py` | Análisis de decisiones en 4º down |
| `valor_turnovers.py` | Valor de los turnovers (basado en EPA) |
| `power_rankings.py` | Power rankings semanales |
| `season_arc.py` | Evolución del rendimiento a lo largo de la temporada |
| `draft_grid.py` | Visualización de picks del draft |
| `draft_success.py` | Evaluación del rendimiento de una clase de draft |
| `proe.py` | Puntos por encima del esperado (PROE) |

## 🛠️ Tecnologías utilizadas

- **Python 3.10+**
- `nfl_data_py` — Datos play-by-play y de jugadores
- `pandas` — Manipulación de datos
- `matplotlib` / `PIL` — Visualización y generación de gráficos
- `numpy` — Cálculos estadísticos

## 🚀 Cómo ejecutarlo

```bash

```
